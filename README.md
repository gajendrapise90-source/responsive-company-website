# Nexa Digital – Responsive Company Website

## Project Overview
Nexa Digital is a modern, responsive, multi-page company website created as part of my web development internship assignment.

The website presents a digital agency's services, company information, and contact details through a clean and professional design.

## Pages
- **Home:** Hero section, company highlights, and call-to-action.
- **About:** Company story, mission, vision, and team information.
- **Services:** Overview of six digital services.
- **Contact:** Contact information and validated contact form.

## Key Features
- Four-page responsive website.
- Responsive navigation bar with mobile hamburger menu.
- Consistent header and footer across all pages.
- Mobile, tablet, and desktop layouts.
- Bootstrap-based responsive grid system.
- Contact form with JavaScript validation.
- Hover effects and clean user interface.
- Reusable CSS styling.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5.3.3

## Design Decisions
- Used deep navy and electric blue for a professional digital-agency identity.
- Maintained consistent typography, colors, navigation, and footer across all pages.
- Used Bootstrap's grid system to create responsive layouts.
- Used CSS media queries and flexible layouts for different screen sizes.
- Added JavaScript validation to improve contact form usability.

## Contact Form Note
The contact form includes front-end validation. It is a demonstration form and does not currently send messages to an email server.

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through Home, About, Services, and Contact.
